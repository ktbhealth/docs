The pages plugin serves custom pages: markdown content in `custom_pages`,
rendered on demand at normalized URL paths, managed through the admin
surface — no deploy needed to publish content.

## Key concepts

- **Content as data** — `path`, `title`, markdown `content`,
  `published`, `showInNav`, `sortOrder`.
- **Path normalization** — `normalizePagePath` is the single validator for
  admin input and request paths; it rejects the `/platform` namespace so
  custom pages can never shadow the admin console.
- **Invisible drafts** — only `published` rows render; drafts 404 for
  visitors rather than 403.
- **Nav contribution** — `showInNav` + `sortOrder` feed the site
  navigation via `chrome.tsx`.
