The RBAC section covers authorization: `packages/rbac` (vocabulary +
`Permissions` service) and `plugins/rbac` (tables `roles`,
`role_permissions`, `subject_roles`, `permission_epoch`, admin UI).

## Key concepts

- **Dynamic roles** — runtime-managed `(resource, action, effect)` grant
  bundles assignable to users and groups; managed at `/platform`.
- **Permission catalog** — `PERMISSION_CATALOG` in
  `packages/rbac/src/vocabulary.ts` is the typed vocabulary grants
  validate against; hand-synced until codegen lands.
- **Epoch invalidation** — `permission_epoch` bumps on grant changes so
  cached permission snapshots are discarded.
- **Two authz modes** — static permix `Def` vs dynamic rbac, unified
  through `entityAuthz`/`requireEntityAccess`.
- **Deny never satisfies** — evaluation order matters; see
  `buildPermissions`.
