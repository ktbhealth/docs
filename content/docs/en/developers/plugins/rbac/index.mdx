The RBAC section covers authorization: `packages/rbac` (vocabulary +
`Permissions` service) and `plugins/rbac` (tables `roles`,
`relation_tuples`, `permission_epoch`, admin UI).

## Key concepts

- **Dynamic roles** — runtime-managed bundles of `(resource, action,
  effect)` grants assignable to users and groups; managed at
  `/platform`.
- **Relation tuples** — `relation_tuples` is the ONLY grant store
  (Zanzibar-style): role grants, role memberships, and object-level
  checks are all rows. The legacy `role_permissions`/`subject_roles`
  tables were dropped in migration `0063`.
- **Permission catalog** — `PERMISSION_CATALOG` in
  `packages/rbac/src/vocabulary.ts` is the typed vocabulary grants
  validate against; hand-synced until codegen lands.
- **Epoch invalidation** — `permission_epoch` bumps on grant changes so
  cached grant sets are discarded.
- **Deny never satisfies** — evaluation order matters; see
  `buildPermissions`.
