---
title: Site structure
description: Where things live in this repo.
---

```
content/docs/          MDX content (audience tabs + meta.json per folder)
src/routes/            TanStack file routes
  docs/$.tsx           docs layout + page renderer
  docs/{$}.md.ts       per-page markdown endpoint
  api/search.ts        Orama search index endpoint
  llms[.]txt.ts        llms.txt index
  llms-full[.]txt.ts   llms-full.txt (full content)
src/lib/source.ts      fumadocs source loader + llms helpers
src/lib/shared.ts      routes, git config, markdown URL helpers
src/styles/app.css     Tailwind v4 + fumadocs-ui presets
alchemy.run.ts         Cloudflare Workers deploy (Alchemy)
vite.config.ts         plugins + env-conditional nitro preset
bunfig.toml            hoisted linker (required for nitro dev)
```

Build output (gitignored): `.output/server` is the nitro Worker bundle;
`.output/public` is the prerendered site and static assets.
