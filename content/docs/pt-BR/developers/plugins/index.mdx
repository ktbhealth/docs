Cada seção abaixo corresponde a um plugin (ou pacote de capability) no
repositório `product` e contém suas tabelas de banco: diagrama ER, o código
`erDiagram` (`schema.mmd`) e referência de colunas/índices por tabela.

Este conteúdo é **gerado** das migrations Drizzle
(`packages/db/drizzle/*.sql`) — não edite manualmente.

## Regenerar

A partir da raiz do repositório `product`:

```bash
bun run db:erd        # regenera
bun run db:erd:check  # drift check de CI (sai 1 se estiver desatualizado)
```

Requer `tbls` no `PATH` (ou `TBLS_BIN`). O script aplica todas as migrations
num banco SQLite temporário e executa `tbls doc` + `tbls out`, gravando em
`docs/content/docs/<locale>/developers/plugins/` para `en` e `pt-BR`.
