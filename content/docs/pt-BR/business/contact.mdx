## Para clínicas e parceiros

Para pilotos, dúvidas de procurement, revisões de segurança ou conversas sobre
implantação, abra uma conversa pelo GitHub da org ou seu contato existente com o
KTB — mencione qual destes você precisa:

- **Piloto / avaliação** — rollout com escopo definido para uma clínica ou equipe.
- **Procurement e conformidade** — questionário de segurança, DPA, requisitos
  de retenção.
- **Implantação** — nuvem privada, self-hosted ou alvos fora da Cloudflare.
- **Integração** — interoperabilidade FHIR/HL7 ou com EHR (em andamento — veja os
  pacotes `interop-*` no repo do produto).

## Para desenvolvedores

Contribuições e dúvidas técnicas passam pelo
[repo do produto](https://github.com/ktbhealth/product) — veja o
[guia de Contribuição](/pt-BR/docs/developers/tutorials/contribute).

## Divulgação responsável

Relatórios de segurança: por favor, **não** abra uma issue pública. Use um canal
privado (GitHub Security Advisories no repo do produto, ou contato direto) e
responderemos prontamente.

<Callout type="info" title="Dados de contato público em breve">
  Uma caixa de entrada dedicada para negócios está sendo configurada. Até lá, o
  GitHub é o canal público canônico da org.
</Callout>
