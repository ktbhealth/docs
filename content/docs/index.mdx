Welcome to the KTB Health documentation site. It covers the `ktbhealth` GitHub
organization — primarily the [product](https://github.com/ktbhealth/product)
monorepo, which powers the KTB Health clinical documentation app.

The docs follow the [Diátaxis](https://diataxis.fr/) framework:

- **Tutorials** — learning-oriented, step-by-step walkthroughs for newcomers.
- **How-to guides** — task-oriented recipes for specific goals.
- **Reference** — factual descriptions of commands, structure, and configuration.
- **Explanation** — understanding-oriented discussion of architecture and
  decisions.
