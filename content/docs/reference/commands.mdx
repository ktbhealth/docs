---
title: Commands
description: npm scripts and what they do.
---

| Command                | Description                                                        |
| ---------------------- | ------------------------------------------------------------------ |
| `bun run dev`          | Vite dev server on :3000 (nitro `vercel` preset)                   |
| `bun run build`        | Production build with the `vercel` preset                          |
| `bun run build:cf`     | Build with `CLOUDFLARE_DEPLOY=1` → nitro `cloudflare_module`       |
| `bun run preview`      | Preview the last build locally                                     |
| `bun run types:check`  | `tsc --noEmit`                                                      |
| `bun run deploy`       | `build:cf` + `alchemy deploy`                                      |
| `bun run deploy:wrangler` | `build:cf` + `wrangler deploy` against nitro's generated config |

Environment variables:

- `CLOUDFLARE_DEPLOY=1` — select the `cloudflare_module` nitro preset.
- `NITRO_PRESET` — explicit nitro preset override (wins over
  `CLOUDFLARE_DEPLOY`).
